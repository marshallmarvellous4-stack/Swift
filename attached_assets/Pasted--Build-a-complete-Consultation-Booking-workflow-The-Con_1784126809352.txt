 



Build a complete Consultation Booking workflow.



The "Consultation" button on the doctors profile should navigate users through a professional healthcare booking experience. 



The workflow should be:



Home Screen

→ Consultation Booking

→ Booking Summary

→ Payment

→ Payment Success

→ Chat with Consultant



The UI should follow the existing SwiftCare design system:



* Primary color: Green (#22C55E)

* White background

* Modern rounded cards

* Clean medical appearance

* Responsive on Android and iOS

* Smooth animations

* Professional typography



---



## Screen 1: Consultation Booking



Create a new screen called:



ConsultationBookingScreen



The page should include:



### Consultant Card



Display:



* Consultant profile photo

* Full name

* Specialty

* Rating

* Consultation fee



Example:



Dr. Sarah Johnson

General Physician

⭐ 4.9

₦5,000



---



### Consultation Type



Allow the patient to choose one option.



Options:



* Chat Consultation

* Voice Call

* Video Call



Use selectable cards.



---



### Date Picker



Allow users to choose a consultation date.



Use a modern calendar component.



---



### Time Selection



Display available time slots such as:



09:00 AM



10:30 AM



12:00 PM



03:00 PM



05:00 PM



Unavailable times should appear disabled.



---



### Reason for Consultation



Provide a multiline text area.



Placeholder:



"Describe your symptoms or reason for consultation..."



Minimum 20 characters.



Maximum 500 characters.



---



### Upload Documents



Allow optional uploads.



Support:



* Lab Results

* Images

* Prescriptions



Display uploaded files as preview cards.



---



### Continue Button



Validate:



* Date selected

* Time selected

* Consultation type selected

* Reason entered



Then navigate to Booking Summary.
